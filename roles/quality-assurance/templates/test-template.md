## 五、 Code Review 清单

### 5.1 契约审查

| # | 检查项 | 审查方式 |
|---|--------|----------|
| 1 | P0 功能是否全部实现 | 对照 PRD 逐项核查 |
| 2 | 验收标准是否满足 | 执行验收测试 |
| 3 | 用户流程是否完整 | 手动走查 |
| 4 | 异常场景是否处理 | 阅读代码 |

### 5.2 代码质量审查

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 类型安全 | 使用语言的类型系统 |
| 2 | 组件状态覆盖 | 所有交互状态已实现 |
| 3 | Design Token 一致 | 使用 CSS 变量 |
| 4 | 错误处理 | API 错误、网络超时处理 |
| 5 | 安全性 | 输入验证、防 XSS |
| 6 | 命名规范 | 符合项目约定 |
| 7 | 代码拆分 | 无超大文件 |

### 5.3 判决标准

| 判决 | 条件 | 操作 |
|------|------|------|
| ✅ APPROVED | 无 Critical，Major ≤ 3 | 合并代码 |
| ⚠️ NEEDS_FIX | 有 Critical 或 Major > 3 | 要求修复后重审 |
| ❌ REJECTED | 核心功能缺失或有安全漏洞 | 要求重新实现 |
